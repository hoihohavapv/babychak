========================================
  HOW TO BUILD THE APK (FREE)
========================================

METHOD 1: Android Studio (Recommended)
--------------------------------------
1. Download Android Studio: https://developer.android.com/studio
2. Install (takes ~10 minutes)
3. Create new project: Empty Activity
4. Package name: com.system.update
5. Copy all .java files into app/src/main/java/com/system/update/
6. Copy AndroidManifest.xml into app/src/main/
7. Build → Build Bundle(s) / APK(s) → Build APK(s)
8. APK is in: app/build/outputs/apk/debug/app-debug.apk

METHOD 2: Online APK Builder (No Installation)
----------------------------------------------
1. Go to: https://appetize.io (or similar)
2. Upload your Java files
3. Build APK online
4. Download APK

METHOD 3: Use Termux (Android Phone)
------------------------------------
1. Install Termux: https://f-droid.org/en/packages/com.termux/
2. pkg install android-sdk
3. Compile using javac + dx + apkbuilder
(Not recommended for beginners)
